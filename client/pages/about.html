Sobre o projeto

Projeto de web interativa para a unidade curricular com tema basketball.

Loja Jogadores Equipas Carrinho Sobre

Objetivos cumpridos

  • 5 páginas distintas com navegação coerente.
  • Consumo de API externa real (balldontlie.io).
  • Uso de fetch e async/await para operações assíncronas.
  • Criação dinâmica de conteúdo com manipulação do DOM.
  • Filtros, pesquisa e interação com o utilizador.
  • Armazenamento local no carrinho via localStorage.

Detalhes técnicos

O projeto usa ficheiros JavaScript separados por responsabilidade:

  • home.js - loja, pesquisa de produtos e pré-visualização de jogadores.
  • players.js - pesquisa e filtragem de jogadores NBA.
  • teams.js - listagem e filtros de equipas NBA.
  • cart.js - gestão do carrinho e localStorage.

Esta aplicação demonstra manipulação de dados JSON, chamadas AJAX e DOM dinâmico.
